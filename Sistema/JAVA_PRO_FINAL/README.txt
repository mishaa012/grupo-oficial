SISTEMA HOSPITALARIO PRO - JAVA V3

VERSIÓN RECOMENDADA PARA PRESENTAR.

NUEVA INTERFAZ V3:
- Tema oscuro moderno con botones más visibles.
- Inicio de sesión con accesos rápidos para cada rol.
- Centro de control con tarjetas clicables y porcentaje de ocupación.
- Mapa interactivo de camillas: buscar, filtrar, seleccionar y ver detalle.
- Acción según estado desde el mapa: asignar, liberar o gestionar estado.
- Acciones rápidas para abrir directamente cada módulo.
- Confirmaciones antes de asignar o liberar una camilla.

MÓDULOS:
- Camillas: agregar, editar, eliminar, ver detalle, buscar, filtrar, liberar y mapa visual.
- Pacientes: crear, editar, ver, eliminar con validaciones y buscar.
- Asignar y liberar camillas.
- Limpieza / falla con botones de estado rápido.
- Triaje: crear, ver detalle, historial por paciente y eliminar (admin).
- Reportes: auditoría, triajes, camillas, pacientes y exportar CSV.
- Herramientas: backup, restaurar, información del sistema y acerca de.
- Persistencia automática.
