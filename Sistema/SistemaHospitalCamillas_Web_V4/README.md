# Sistema Hospitalario PRO V4 — Página web

Proyecto listo para abrir y editar en **Visual Studio Code**. Está hecho solo con HTML, CSS y JavaScript; no necesitas instalar Java, MySQL ni Node.js para usarlo.

## Abrir en Visual Studio Code

1. Descomprime el archivo `.zip`.
2. Abre **Visual Studio Code**.
3. Selecciona **Archivo > Abrir carpeta**.
4. Elige la carpeta `SistemaHospitalCamillas_Web_V4`.
5. Abre el archivo `index.html`.
6. Para verlo mejor, instala la extensión **Live Server** y presiona **Go Live** abajo a la derecha.

También puedes hacer doble clic en `ABRIR_EN_NAVEGADOR.bat` para abrirlo directamente en tu navegador.

## Funciones incluidas

- Inicio de sesión por roles y accesos rápidos.
- Dashboard con indicadores, ocupación y alertas.
- Mapa de camillas con colores: libre, ocupada, limpieza y falla.
- Búsqueda, filtros, detalle y acciones por camilla.
- Registro, edición y consulta de pacientes.
- Asignar y liberar camillas.
- Registrar limpieza y fallas con observaciones.
- Registro de triaje.
- Reportes CSV y respaldos JSON.
- Datos guardados en el navegador mediante almacenamiento local.
